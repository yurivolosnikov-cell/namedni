# Намедни. Türkiye

Турецкая республика по годам в формате «Намедни» Парфёнова.

## Где что лежит

| Папка | Что внутри | Правило |
|---|---|---|
| `years/` | Тексты годов (`1985.md` …) — **источник правды** | Правим только здесь |
| `pilot/` | Пилот 1985 в новом стиле + его вёрстка | Образец для остальных лет |
| `ref/` | Справочники: хронология, база феноменов, ВВП/референдумы, актёры, фильмы, темы | Читаем при работе над годом |
| `ref/ocr/` | Распознанный текст сканов книг (`kniga/IMG_xxxx.txt`, `1923-1950/`) | Ищем по нему вместо фото |
| `ref/сканы_по_годам.md` | Какой скан к какому году | |
| `img/` | Отобранные фото для вёрстки, по годам (имена — `img/NAMING.md`) | Только то, что идёт в полосу |
| `site/` | Готовый HTML — **генерируется**, руками не правим | `python3 tools/generate_html.py` |
| `tools/` | Скрипты сборки | |

Сырые сканы книг, Galleria, газета и PDF Парфёнова лежат **вне проекта**: `../namedni_источники/`.
Там же — полный бэкап старой git-истории (`namedni_full_history_2026-10-20.bundle`).

## История правок
Git + GitHub (`yurivolosnikov-cell/namedni`). В git — только текст, скрипты и `img/`.
Сканы, PDF и временные файлы в git не кладём (см. `.gitignore`).
Временное (OCR-прогоны, черновики) — в `_tmp/`, папка игнорируется и периодически чистится.
