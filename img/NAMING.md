# Конвенция именования фотографий

## Структура папок

```
img/
  1980/
  1981/
  ...
  1991/
```

## Формат имени файла

```
{год}_{slug-феномена}_{порядковый-номер}.{расширение}
```

### Правила slug:
- только строчные латинские буквы и цифры
- слова разделяются дефисом `-`
- транслитерация турецких слов (без диакритики): ş→s, ğ→g, ı→i, ö→o, ü→u, ç→c
- максимум 30 символов в slug

### Расширения:
- `.jpg` — фотографии (основной формат)
- `.png` — если оригинал PNG (скриншоты, схемы)
- `.webp` — оптимизированные версии

## Примеры

| Феномен | Файл |
|---|---|
| 12 сентября (фото 1) | `1980/1980_12-eylul_01.jpg` |
| 12 сентября (фото 2) | `1980/1980_12-eylul_02.jpg` |
| Банкер Кастелли | `1982/1982_banker-kastelli_01.jpg` |
| Наим в Сеуле | `1988/1988_naim-seul_01.jpg` |
| Берлинская стена | `1989/1989_berlin-duvari_01.jpg` |
| Галатасарай в полуфинале | `1989/1989_galatasaray-sampiyonlar-ligi_01.jpg` |
| Война в Заливе | `1990/1990_korfez-savasi_01.jpg` |

## Как использовать в .md файлах

```markdown
![Описание фото](img/1980/1980_12-eylul_01.jpg)
*Подпись: что изображено, место, дата, источник.*
```

## Источники и лицензии

Хранить рядом с файлом текстовый sidecar если источник требует атрибуции:
```
1980_12-eylul_01.txt
```
Содержание: URL источника, автор, лицензия (CC-BY, Public Domain и т.д.)
